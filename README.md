# 🛒 AI-Powered Grocery Sell, Order & Tracking Web App

A modern **Grocery E-Commerce Web Application** built using **AI-assisted development tools** like AntiGravity IDE and Claude Code.

This project demonstrates how developers can leverage **AI coding assistants and AI IDEs** to build real-world applications faster and more efficiently.

---

## 🚀 Project Overview

This web application allows users to:

- Browse grocery products
- Place orders online
- Track their orders
- Experience a modern AI-assisted development workflow

The project was built as an experiment to explore **AI-powered development workflows** and understand how tools like **Claude Code + AntiGravity IDE** can accelerate software development.

---

## ✨ Features

- 🛒 Grocery Product Listing
- 📦 Order Placement System
- 📍 Order Tracking
- 🤖 AI-assisted development workflow
- ⚡ Faster development using AI tools
- 💻 Clean and simple web interface
